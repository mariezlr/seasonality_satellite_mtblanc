# seasonality_satellite_mtblanc

Code and processed data to reproduce the analyses and figures of the study
**"Slope-dependent seasonal glacier velocity cycles in the Mont Blanc massif"**.

> **Note** — This repository accompanies a manuscript currently under review.
> A permanently archived version with a DOI will be released on Zenodo upon
> acceptance.

---

## 1. Quick start

```bash

# Reproduce the figures (requires data/output/analysis_dataset.nc, see section 4)
cd src
python plot_fig1.py
python plot_fig2.py
python plot_fig3.py
python plot_sup.py
```

All manuscript figures are written to `figures_paper/`.

## 2. Figures

| Figure | Script | Output |
|---|---|---|

### Supplementary figures

`src/plot_sup.py` produces all six at once, or selected ones:
`python plot_sup.py 3 5`.

| Figure | Content | Output |
|---|---|---|
| S1 | Velocity time series at two representative pixels | `figS1_2pixels_ts` |
| S2 | Daily velocity and precipitation | `figS2_daily_vel_precip` |
| S3 | Basal shear stress against surface slope | `figS3_taub_vs_slope` |
| S4 | Individual data-quality masks | `figS4_masks_map` |
| S5 | Figure 2 recomputed without quality masks | `figS5_phasing_nomask` |
| S6 | Amplitude and slope maps of the massif | `figS6_amplitude_slope_maps` |

Figure S7 (monthly analysis of raw velocity data) was produced by Nathan Lioret
with a processing script that is not part of this repository. The resulting
raster is provided so that the figure can be redrawn from it.

Figure 3 (C) is synthetic: the bed, cavities and conduits are generated by the script,
and the drawing is adjusted by hand, so the script alone reproduces a similar version 
of the panel instead of the exact version.

## 3. Repository structure

```
src/                analysis and figure code
data/               input and intermediate data (not versioned, see section 5)
figures_paper/      the 9 reproducible figures of the manuscript
```

### Code

**Processing pipeline**

| File | Role |
|---|---|
| `utils.py` | utility functions and file paths |
| `data_exploration.py` | loads and formats the velocity cube, reference grid, topography, glacier outlines, GPS validation points and meteorological data. This module is imported by all others |
| `masks.py` | builds 2D GeoTIFF quality masks (shadow, SNR, observation count, mean velocity, stable areas) |
| `peaks.py` | day-of-year and value of velocity minima, maxima and inflection points |
| `melt.py` | annual melt cycles from daily temperature (Positive Degree Day) |
| `processing.py` | **main pipeline**: combines all of the above and writes `analysis_dataset.nc` |
| `friction_law.py` | basal shear stress and effective pressure relationships |

**Figures**

| File | Role |
|---|---|
| `plots_config.py` | shared paths, dataset loading and figure saving for all figure scripts |
| `plot_fig1.py`, `plot_fig2.py`, `plot_fig3.py` | one manuscript figure each |
| `plot_sup.py` | the six supplementary figures |

Paths are derived from the location of `plots_config.py`.

## 4. Reproducing the analysis from scratch

1. **Obtain the velocity cubes.** TICOI-interpolated Sentinel-2 velocity cubes
   are required by `data_exploration.py`. They are not redistributed here
   because of their size; see section 5.

2. **Build masks, peaks and melt cycles.**
   ```bash
   cd src
   python masks.py
   python peaks.py
   python melt.py
   ```

3. **Run the main pipeline.**
   ```bash
   python processing.py
   ```
   This writes `data/output/analysis_dataset.nc` (~5.8 GB), containing all
   computed variables on a common reference grid.

4. **Produce the figures** (see section 2).

Only step 4 is needed if `analysis_dataset.nc` is already available.

## 5. Data

### Provided with this repository

Small derived products are versioned under `data/`:

- `data/output/tau_b_mean_8_glaciers.csv` — mean basal shear stress per
  surface-slope bin, from full Stokes simulations on eight Alpine glaciers
- `data/topography/mtblanc_glaciers_outlines.csv` — RGI glacier outlines,
  reprojected to EPSG:32632

### Available separately

Larger processed files (per-glacier CSV tables, quality masks and peak
rasters, ~200 MB) will be archived at a Zenodo DOI upon acceptance.

`analysis_dataset.nc` (5.8 GB) is not archived; it is regenerated by step 3
above.

### Input data sources

| Dataset | Source |
|---|---|
| Surface velocities | Sentinel-2 image pairs, processed with TICOI |
| Background image | Sentinel-2 L2A, tile T32TLR, 7 September 2025 — [Copernicus Data Space](https://dataspace.copernicus.eu/) |
| Digital elevation model | `Mt_Blanc_small_UTM32N.tif`, 1407 x 1610 px, EPSG:32632 |
| Glacier outlines | Randolph Glacier Inventory |
| Temperature and precipitation | SAFRAN reanalysis, Meteo-France |
