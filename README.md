### Code files

The analysis code is located in the src/ directory and organized as follows:

utils.py: Utility functions and file paths for data processing.

data_exploration.py: Prepares and formats the main velocity dataset, reference grid parameters, topographic files (satellite images, DEM, glacier outlines), GPS validation data, and meteorological data (discharge, precipitation, melt rate).

masks.py: Creates 2D GeoTIFF files to eliminate low-quality data.

peaks.py: Generates 2D GeoTIFF files with the day of the year (DOY) and values of minimum and maximum velocity for each point.

melt.py: Computes annual melt cycles for each point using the Positive Degree Day method and stores results in 3D NetCDF file.

processing.py: Integrates all previous steps to process time series, clean data, and compute key parameters (detrended time series, mean annual velocity cycles, peaks, inflection days). Combines masks, computes DEM, slope, and annual melt cycle, aligning all parameters on the same reference grid. Outputs a NetCDF file named analysis_dataset.nc.

plots_main.py & plots_annex.py: Generate manuscript figures and additional verification/analysis figures from analysis_dataset.nc. Outputs are saved in the figures/ directory.


## Recommended Workflow

### 1. Data Preparation: 
Run utils.py and data_exploration.py to prepare and explore the initial data.

### 2. Mask Creation, Peak Detection, Melt Cycle Calculation:
Run masks.py to create data quality masks.
Run peaks.py to detect velocity peaks.
Run melt.py to compute annual melt cycles.

### 3. Main Processing:
Execute processing.py to integrate all processes and generate the analysis_dataset.nc file.

### 4. Visualization:
Use plots_main.py and plots_annex.py to generate the figures.


## Outputs
Intermediate outputs generated by masks.py, peaks.py, and melt.py are stored in data/output/.
data/output/analysis_dataset.nc: NetCDF file containing all computed parameters aligned on the same reference grid.
